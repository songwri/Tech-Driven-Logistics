# 방명록 Forms 만들기 (외부 방문객용)

방명록은 두 곳에서 남길 수 있습니다.

| 어디서 | 누가 | 저장 |
| --- | --- | --- |
| 앱 `scrGuest` 의 [방명록 남기기] | 센터 현장 태블릿 (직원 계정으로 앱을 열어 둠) | 흐름 E → `Guestbook` |
| **이 Forms** | 방문을 마친 외부 방문객 (방문 완료 메일의 링크) | 흐름 F → `Guestbook` |

외부 고객사 방문객은 회사 계정이 없어 Power Apps 를 열 수 없습니다. 그래서 웹 `/guestbook/` 의 작성 화면과 같은 질문을 Forms 로 받습니다.
어느 쪽으로 남겨도 흐름 G 가 가명 처리한 공개용 행을 `GuestbookPublic` 에 만들어, 앱 방명록 화면에 같이 흐릅니다.

## 1. 새 양식

1. [forms.office.com](https://forms.office.com) → **새 양식**
2. 제목: `TDL Lab 방명록`
3. 설명:
   ```
   센터 방문은 어떠셨나요? 남겨 주신 소감은 서비스 개선에 쓰이고, 방명록 화면에는 가명(예: 홍**, L**)으로만 표시됩니다.
   ```

## 2. 질문 (웹 작성 화면과 같은 순서)

| # | 질문 | 형식 | 필수 | 비고 |
| --- | --- | --- | --- | --- |
| 1 | 어떤 투어에 참여하셨나요? | 선택(하나) | 예 | `종합 투어` · `TDL Lab 투어` · `메가와이즈 센터 투어` (시화MTV 를 열면 그 투어도 추가) |
| 2 | 이번 방문은 어떠셨나요? | **등급(별 5개)** | 예 | Forms 별점은 1점 단위입니다 (웹 · 앱은 0.5점 단위) |
| 3 | 방문 소감 | 텍스트 | 예 | 100자 이내로 안내 (넘으면 흐름이 100자로 자름) |
| 4 | 이름 | 텍스트 | 예 | 공개 화면에는 홍** 처럼 가명 |
| 5 | 회사명 | 텍스트 | 예 | 공개 화면에는 L** 처럼 가명 |
| 6 | 팀명 | 텍스트 | 아니요 | |
| 7 | 직책 | 텍스트 | 예 | |
| 8 | 신청번호 (자동, 고치지 마세요) | 텍스트 | 아니요 | 방문 완료 메일 링크에 미리 채워짐 |
| 9 | 개인정보 수집 · 이용 동의 | 선택(하나) | 예 | 선택지 `동의합니다` 하나 |

9번 부제목 (웹 작성 화면의 '자세히' 와 같은 문구):
```
· 항목: 이름, 회사명, 팀명(선택), 직책, 별점 · 소감 · 참여 투어
· 목적: 방명록 등록 · 게시(이름과 회사명은 가명 처리해 공개), 방문 서비스 개선
· 가명 처리: 공개 화면에는 가명(예: 홍**, L**)만 보이고, 실명 · 실제 회사명은 담당 관리자만 접근해 관리
· 보관: 등록일로부터 1년 후 파기, 삭제를 원하시면 담당자에게 요청
· 동의를 거부할 수 있으나, 거부하시면 방명록을 남기실 수 없습니다.
```

## 3. 설정
- 응답할 수 있는 사람: **누구나 응답할 수 있음**
- 한 사람당 응답 1개: 끄기 · 응답 알림: 끄기

## 4. 미리 채워진 링크 (방문 완료 메일용)
1. `...` → **미리 채워진 링크 가져오기**
2. 1번 투어에서 아무 선택지나 고르고, 8번 신청번호에 `REQNO` 입력 → 링크 복사
3. 링크에서 투어 값 부분(예: `TDL%20Lab%20%ED%88%AC%EC%96%B4`)을 `TOURQ` 로 바꿉니다.
4. 이 주소를 흐름 C 의 `방명록링크` 변수에 넣습니다 (`flows.md` 흐름 C · 완료). 흐름이 `TOURQ` · `REQNO` 를 그 신청의 투어 · 번호로 바꿔 보냅니다.

미리 채워진 링크 기능이 꺼진 회사라면 3 ~ 4 없이 일반 링크를 넣어도 됩니다 (방문객이 투어를 직접 고름).

## 5. 응답 데이터
흐름 F 가 `Guestbook` 으로 옮긴 뒤에는 Forms 쪽 응답이 필요 없습니다. 한 달에 한 번 `응답` 탭 → `모든 응답 삭제` 를 하세요.
