# 참석자 정보 입력 Forms 만들기

사업개선팀이 정한 방식입니다. 신청자는 참석자 개인정보를 **대신 입력하지 않습니다.**
참석자가 Forms 링크를 받아 **본인이 직접 입력하고 동의**하면, Power Automate 가 SharePoint `VisitAttendees` 목록으로 옮겨 신청 건별로 모읍니다.

## 1. 새 양식 만들기

1. [forms.office.com](https://forms.office.com) → **새 양식**
2. 제목: `TDL 센터 방문 · 참석자 정보 입력`
3. 설명(그대로 붙여넣기):

   ```
   LX판토스 센터 방문을 위해 참석자 정보를 받습니다.
   입력하신 정보는 출입 등록 · 방문 안내에만 쓰이며, 방문일로부터 1년 뒤 삭제됩니다.
   맨 위의 '신청번호'는 자동으로 채워져 있으니 고치지 마세요.
   ```

## 2. 질문 (순서대로)

| # | 질문 | 형식 | 필수 | 비고 |
| --- | --- | --- | --- | --- |
| 1 | 신청번호 (수정하지 마세요) | 텍스트 | 예 | 링크에 미리 채워짐 |
| 2 | 성함 | 텍스트 | 예 | |
| 3 | 직책 | 텍스트 | 예 | 예) 부장 |
| 4 | 회사 · 소속 | 텍스트 | 예 | 예) 한빛식품 물류기획팀 |
| 5 | 이메일 | 텍스트 | 예 | 방문 안내 메일을 받을 주소 |
| 6 | 차량번호 (차로 오시는 경우) | 텍스트 | 아니요 | 주차 등록용 |
| 7 | 직무 | 선택(여러 개) | 아니요 | 경영진 · 영업 · 기획 · 마케팅 · 구매 · 운영 · 물류 · 품질관리 · IT/개발 · R&D/연구개발 |
| 8 | 개인정보 수집 · 이용 동의 | 선택(하나) | 예 | 선택지 `동의합니다` 하나만 |

8번 질문의 **부제목**(질문 오른쪽 `...` → 부제목)에 아래를 넣습니다.

```
수집 항목: 성함, 직책, 회사 · 소속, 이메일, (선택) 차량번호 · 직무
이용 목적: 센터 출입 등록, 방문 일정 안내, 방문 후 만족도 · 개선 의견(방명록) 요청 메일 발송
보유 기간: 방문일로부터 1년 (이후 삭제)
동의하지 않으실 수 있으나, 이 경우 출입 등록이 어려워 방문이 제한될 수 있습니다.
```

> **방명록 요청 메일 (웹 PR #89 · #91 과 같음)**: 방문 완료 후 정보를 낸 참석자에게 만족도 · 의견(방명록) 요청 메일이 한 번 갑니다.
> 이 용도는 위 '이용 목적' 에 들어 있어야 하므로, **이 문구로 바꾼 날짜를 흐름 C 의 `후기기준일` 에 적어 두세요.** 그 전에 신청된 건에는 메일을 보내지 않습니다.

5번 이메일 질문은 `...` → **제한** → **이메일**로 두면 형식이 틀린 주소를 막아 줍니다. (메뉴에 없으면 생략)

## 3. 응답 설정

오른쪽 위 `...` → **설정**

- **응답할 수 있는 사람: `누구나 응답할 수 있음`** (참석자가 외부 고객사이므로).
  회사 정책상 외부 응답이 막혀 있으면 IT 팀에 이 양식만 허용해 달라고 요청하세요.
- `한 사람당 응답 1개`는 **끄기** (외부 응답자는 로그인하지 않으므로 의미 없음)
- `응답 수신 시 알림 받기`는 끄기 (Power Automate 가 처리)

## 4. 미리 채워진 링크 만들기 (신청번호 자동 입력)

1. 오른쪽 위 `...` → **미리 채워진 링크 가져오기**
2. 1번 질문(신청번호)에 `REQNO` 라고 입력 → **미리 채워진 링크 가져오기** → **복사**
3. 복사한 주소를 `3-powerapps/App.Formulas.txt` 맨 위 `FormsPrefillUrl` 값으로 붙여넣습니다.
   주소 안에 `REQNO` 가 그대로 들어 있어야 합니다. 앱이 신청할 때 이 자리를 실제 신청번호로 바꿉니다.

   ```
   FormsPrefillUrl = "https://forms.office.com/Pages/ResponsePage.aspx?id=xxxxxxxx&r3f2a...=REQNO";
   ```

> 메뉴 이름이 다르면 `공유` → `미리 채워진 링크`를 찾아보세요. 이 기능이 꺼져 있는 회사도 있습니다.
> 그때는 신청번호를 참석자에게 메일로 알려 주고 직접 입력하게 하면 됩니다(흐름 B 가 번호가 틀린 응답을 따로 알려 줍니다).

## 5. 응답 데이터 보관

- Forms 에도 응답이 남습니다. 흐름 B 가 SharePoint 로 옮긴 뒤에는 Forms 쪽 응답이 필요 없으므로,
  **한 달에 한 번 `응답` 탭 → `...` → `모든 응답 삭제`** 를 하거나, 담당자를 정해 정기적으로 지우세요.
- SharePoint `VisitAttendees` 는 흐름 D(보관 기간 정리)가 방문일 1년 뒤 자동으로 지웁니다.
