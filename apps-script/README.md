# TDL Lab 백엔드 설정 (서버 비용 0원 · 토큰 불필요)

사이트는 GitHub Pages 정적 호스팅이라 서버가 없습니다. Google Apps Script 웹앱을
배포하면 **URL 하나만** 사이트에 넣으면 되고, 토큰·API 키를 사이트 코드에 두지
않습니다. 시트가 그대로 관리자 화면이 됩니다.

## 설계 구조

**서버를 빌리지 않으므로 월 비용이 발생하지 않습니다.** 구글 계정의 Apps Script
할당량(하루 메일 100통, 무료 계정 기준) 안에서 동작합니다.

```
[방문자 브라우저]
   │
   │ ① 예약 신청 (POST)                     ② 방명록 작성 (POST)
   ▼                                          ▼
┌──────────────────────────────────────────────────────┐
│  Google Apps Script 웹앱  (무료 · 상시 대기 · URL 1개)   │
│  · 요일/시간대 검증 (월·수·금, 10:00·14:00)              │
│  · 이름/소속 마스킹                                     │
└───────┬───────────────────────────────┬──────────────┘
        │                               │
        ▼                               ▼
  MailApp.sendEmail            스프레드시트 append
  daehyun.kim1@lxpantos.com    (guestbook / reservations 시트)
  · 예약: 즉시 메일 수신          · 예약: 이력 보관용
  · 방명록: 실명 포함 통보        · 방명록: 사이트 표시용 원본
                                        │
                                        │ ③ 방명록 조회 (GET)
                                        ▼
                                 [사이트 최하단 방문자 기록]
```

**예약**은 요청하신 대로 접수 즉시 `daehyun.kim1@lxpantos.com`으로 메일이 갑니다.
메일의 회신 주소(Reply-To)가 신청자 이메일로 지정되어 있어, 받은 메일에서 바로
**회신 버튼만 누르면 신청자에게 답장**이 갑니다. 시트 기록은 이력 확인용이며 지워도
메일 발송에는 영향이 없습니다.

**방명록은 메일만으로는 처리할 수 없습니다.** 사이트 하단에 목록으로 보여줘야 하니
어딘가에 남아 있어야 하고, 그 저장소가 시트입니다. 시트는 무료라 추가 비용은 없습니다.

| 저장 위치 | 내용 |
| --- | --- |
| `guestbook` 시트 | 방명록. 표시용(마스킹) 값과 실명·실제 소속이 함께 기록됩니다. |
| `reservations` 시트 | 예약 신청. 시간대·연락처·이메일·방문차량 포함. |
| 팀 메일 | 방명록·예약 모두 등록 즉시 자동 발송. |

사이트로 나가는 것은 **마스킹된 값뿐**입니다. 실명과 연락처는 시트와 메일에만 남습니다.

## 설정 (약 5분, 1회)

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다. (이름 예: `TDL Lab`)
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 편집기의 기본 코드를 지우고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
   - 수신 메일 주소를 바꾸려면 파일 상단 `MAIL_TO` 값을 수정하세요.
4. 우측 상단 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인(본인 구글 계정)
5. 발급된 **웹 앱 URL**을 복사합니다.
   (`https://script.google.com/macros/s/…/exec` 형태)

## 사이트에 연결

GitHub 저장소 → **Settings → Secrets and variables → Actions → Variables** 탭 →
**New repository variable**

- Name: `VITE_LAB_API`
- Value: 위에서 복사한 웹 앱 URL

저장 후 다음 배포부터 예약·방명록이 실제로 접수됩니다.
(변수를 설정하기 전까지 방명록은 브라우저 로컬 저장으로만 동작하고, 예약은
"서버 연결 전" 안내가 표시됩니다.)

## 코드를 수정한 경우

Apps Script 편집기에서 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를
해야 반영됩니다. URL은 그대로 유지됩니다.
